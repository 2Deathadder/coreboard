Why Coreboard

The Armoury Crate equivalent, built for Linux

On Windows, manufacturers ship one panel to tune everything. On Linux, you had to juggle a dozen command-line tools. Coreboard brings them together in a polished dark interface.

  • Native and lightweight: written in C with GTK4, starts instantly, no embedded web engine.
  • It adapts to your PC: it detects what your hardware really exposes and hides the rest.
  • No account, no telemetry: everything stays on your machine.
Features

All your hardware, in one place

Every setting goes through standard Linux interfaces: power-profiles-daemon, sysfs, D-Bus, polkit.

Performance modes

Silent, Balanced, Turbo: one click switches the system power profile.

CPU and GPU

Turbo Boost, energy preference, governor, temperatures, frequencies and hybrid GPU mode.

Display

Refresh rate, brightness and night light, on Hyprland, Sway, KDE, GNOME or X11.

RGB lighting

Per-zone effects, custom colors and a Music mode that makes the keyboard react to sound.

Scenarios

When a game gets focus, Coreboard applies the mode and refresh rate you chose, then restores your settings.

Macros

Record key sequences, replay them with repeats and bind them to a global shortcut.

Game library

Steam, Epic (Legendary), GOG, Lutris and game apps, gathered and launched in one click.

Windows games

Proton-GE and umu-launcher, DLSS, ray tracing, GameMode, MangoHud and a check-up that tunes your system.

FitGirl Repacks

From repack to installed game, without leaving Coreboard

Search for a FitGirl repack, download it and install it in Wine in a few clicks. No download manager, no terminal juggling.

  1. SearchResults from the FitGirl catalog show up right inside the app.
  2. DownloadEight connections per file, exact resume after a dropout, a pause or a reboot. Optional files (voices, bonus) are skipped.
  3. Extract and install7-Zip extracts the archives, then installation runs on its own, with no windows at all, in Wine (Proton-GE) with a dedicated prefix. Progress shows in Coreboard.
  4. PlayThe game joins “Windows games” with DLSS, GameMode and MangoHud. Archives can then be deleted to free up space.

Respect copyright law in your country: only download games you have the right to use. Coreboard is not affiliated with FitGirl Repacks and hosts no files.

Installation

Install Coreboard in two minutes

Pick your distribution and paste the commands into a terminal.

# native package: cooling daemon and udev rule included
$ git clone https://github.com/2Deathadder/coreboard.git
$ cd coreboard/packaging/arch && makepkg -si
$ sudo apt install -y git
$ git clone https://github.com/2Deathadder/coreboard.git && cd coreboard
$ make deps && make && make install
$ sudo dnf install -y git
$ git clone https://github.com/2Deathadder/coreboard.git && cd coreboard
$ make deps && make && make install
$ sudo zypper install -y git
$ git clone https://github.com/2Deathadder/coreboard.git && cd coreboard
$ make deps && make && make install

Then launch coreboard from your app menu. A keyboard shortcut on coreboard --toggle opens and closes the window.

Frequently asked questions

FAQ

Is Coreboard an Armoury Crate or MSI Center alternative for Linux?

Yes. Coreboard brings together in one native app what Armoury Crate or MSI Center offer on Windows: performance modes, CPU and GPU tuning, display, RGB lighting, per-app scenarios and game management. It is affiliated with neither ASUS nor MSI.

Which Linux distributions does Coreboard run on?

Arch Linux and its derivatives (Omarchy, CachyOS, EndeavourOS, Manjaro), Debian 13 and Ubuntu 24.04 or newer, Fedora 38 or newer and openSUSE Tumbleweed. GTK 4.10 or newer is required.

Which desktops are supported?

Hyprland, Sway, KDE Plasma, GNOME and X11 desktops. Features adapt: refresh rate through the desktop, native night light on GNOME and KDE, detection of XWayland games.

Does my PC have to be an MSI or an ASUS?

No. Coreboard detects what your PC actually exposes (Intel, AMD or ARM CPU, NVIDIA, AMD or Intel GPU, display, battery) and hides what isn't there. Only keyboard lighting and adaptive cooling are specific to some MSI laptops.

Is Coreboard free?

Yes, Coreboard is free and open-source software under the GPL-3.0 license. The source code is on GitHub.
